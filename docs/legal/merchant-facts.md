# بيانات البائع المطلوبة لصفحات السياسات

تُعرض بيانات النشاط من إعدادات المتجر عبر نقطة إعدادات العلامة التجارية العامة. راجعها مع صاحب المنشأة قبل النشر.

| البيان | المصدر الحالي | الإجراء قبل النشر |
|---|---|---|
| الاسم القانوني للبائع | إعداد `legal_name` | إدخال الاسم المطابق لمستندات المنشأة |
| الاسم التجاري | إعداد `company_name` | تأكيد أنه يطابق العلامة المستخدمة في المتجر |
| العنوان | إعداد `company_address` | إدخال عنوان النشاط الصحيح |
| الهاتف والبريد الإلكتروني | إعدادا `company_phone` و`company_email` | إدخال وسيلتي تواصل فعالتين |
| رقم السجل التجاري | إعداد `commercial_register` | إدخال الرقم المسجل والتحقق منه |
| رقم التسجيل الضريبي | إعداد `tax_number` | إدخاله إذا انطبق على وضع المنشأة |
| طرق الدفع والرسوم والمدة | إعدادات الدفع وعرض الشحن في صفحة الشراء | التأكد من تطابق البيانات الظاهرة مع إعدادات التشغيل |
| مزودو الدفع والشحن والاستضافة وأدوات التحليل | تكوينات الخدمات الفعلية | تحديث سياسة الخصوصية عند إضافة مزود أو تغيير غرض المعالجة |

لا تُدرج أرقامًا أو عناوين تجريبية في الصفحات العامة. يراجع محامٍ مصري النصوص المنشورة ووضع الإلزام الضريبي قبل الإطلاق.
